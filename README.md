# JNIC

A Java native obfuscator that transpiles JVM bytecode to C, cross-compiles it via [Zig](https://ziglang.org/), and embeds the resulting shared library inside your jar. Methods become native — no bytecode left to decompile.

## How it works

```
input.jar → parse classes → select methods → transpile to C
         → zig cc (cross-compile per target)
         → rewrite classes (strip code, mark native)
         → inject loader + embed .dll/.so/.dylib
         → output-protected.jar
```

Your methods stop existing as bytecode. They are compiled machine code loaded at runtime through JNI.

## Features

- **Full JVMS opcode coverage** — every instruction except JSR/RET and ConstantDynamic
- **Cross-compilation** — one config builds for Windows/Linux/macOS on x64 and ARM64
- **String encryption** — all string literals ChaCha20-encrypted, decrypted lazily in C
- **Control flow obfuscation** — program counters relabeled with per-method XOR keys
- **Zero dependencies** — protected jars need nothing beyond the JVM
- **Interface-safe** — mixin classes and interfaces pass through untouched
- **Kotlin-compatible** — handles Kotlin-generated bytecode patterns

## Quick start

```bat
java -jar jnic-1.0.0.jar input.jar output.jar config.xml
```

See [OBFUSCATING.md](OBFUSCATING.md) for the full guide including folder setup, config format, target list, and selection rules.

## Requirements

| | Obfuscator | Protected jar |
|---|---|---|
| JDK 25+ | ✓ (full JDK, not JRE) | any JRE 8+ |
| [Zig 0.13.0](https://ziglang.org/download/) | ✓ | |

The obfuscator requires a full JDK because it reads JNI headers from `java.home/include` during compilation.

## Input constraints

- Class file version 52+ (Java 8+)
- No `JSR`/`RET` subroutines
- No `ConstantDynamic` entries
- Constructors and interface default methods are not nativized

## Building from source

```bat
git clone https://github.com/YOUR_USERNAME/JNIC.git
cd JNIC
set JAVA_HOME=path\to\jdk-25
.\gradlew.bat clean fatJar
```

Output: `build/libs/jnic-1.0.0.jar`
